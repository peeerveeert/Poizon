# Poizon Orders

Веб-приложение для учёта совместных заказов из Китая: товары, закупки, участники, доставка, себестоимость и прибыль.

**Приложение:** https://peeerveeert.github.io/Poizon/

## Основные возможности

- Заказы клиентов и личные покупки в разделе «Наши».
- Объединение вещей в закупки по общему тегу.
- Учёт участника каждой вещи; одинаковые имена можно различать фамилией.
- Распределение по весу международной доставки, доставки по РФ, защиты от рисков и таможенной пошлины.
- Сводка по закупке: товары, расходы объединения, общий итог и сумма каждого участника.
- Расчёт себестоимости, страховки, пошлины, комиссии и итоговой цены для клиента.
- Этапы заказа от черновика до выдачи, архив готовых заказов и статистика прибыли.
- Формирование клиентского чека и печать в PDF.

## Как пользоваться

1. Добавить вещь, участника или клиента и тег закупки.
2. Указать цену в юанях, курс, количество и вес.
3. В блоке «Итоги объединения» выбрать закупку и внести фактические расходы.
4. Нажать «Распределить по весу» — доли и суммы участников рассчитаются автоматически.

## Хранение данных

По умолчанию данные сохраняются в браузере устройства. В настройках можно подключить Supabase для синхронизации между телефоном и компьютером.

Приложение состоит из одного файла `index.html` и публикуется через GitHub Pages.
